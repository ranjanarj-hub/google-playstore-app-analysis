# Google Play Store Apps Analysis 📱

## Overview
Data analysis project on 10,000+ Google Play Store apps 
using Python, Pandas, Matplotlib, Seaborn and Plotly.

## Dataset
- Source: Kaggle - Google Play Store Apps
- 10,357 apps after cleaning
- 64,295 user reviews

## Key Findings
- 92.6% of apps are FREE
- FAMILY category has the most apps (1,943)
- COMMUNICATION apps get the most installs
- Average app rating is 4.19 out of 5
- 64.1% of user reviews are POSITIVE

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

## Project Structure
- data/raw/ - Original datasets
- google_playstore_analysis.ipynb - Main analysis notebook
- cleaned_playstore_data.csv - Cleaned dataset
